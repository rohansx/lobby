Authentication

Send the project's secret key as a bearer token. You get it once when you create the project; Rotate secret key on the project's Overview makes a new one and stops the old one working.

curl https://trylobby.app/v1/stats -H "Authorization: Bearer sk_…"

The secret key can read every address on the list. Keep it on your server, never in a browser or mobile app. Public pages use the public pk_… key instead, which can only add signups.

On Lobby Cloud, the API comes with the Launch and Pro plans. On the Free plan every API call answers 402.

Requests and errors

Send JSON with Content-Type: application/json; responses are JSON. Errors have a status code and a readable message:

{ "ok": false, "error": "invalid secret key" }
StatusMeaning
400The request body or a parameter is wrong.
401Missing or invalid secret key.
402Lobby Cloud only: your plan doesn't include this, or you've hit a limit. The body includes "upgrade": true.
404No such signup, webhook or invite in this project.
422Signup rejected, for example an invalid email address.
429Too many requests. Wait a few minutes.

Timestamps are Unix seconds.

GET/v1/signups/{id}

One signup, including its current position if they're confirmed.

POST/v1/signups/{id}/joined

Marks someone as having signed up for your product. Fires signup.joined.

DELETE/v1/signups/{id}

Marks them removed. With ?hard=1, deletes them and keeps only a hash of the address so it can't be added again.

Invites

POST/v1/invites

Send {"count": 50} to invite the next 50 people in line, or {"ids": [12, 31]} for specific people. Each gets an invite email.

{ "invited": 50, "data": [ …signups… ] }

POST/v1/invites/redeem

Send {"token": "…"} (the ?wl= value from the invite link) or {"email": "…", "code": "K7PD-3XQM"}. Returns the signup, now joined; 404 if the invite is unknown or already used. See Invites and launch day.

Exports

GET/v1/export.csv

GET/v1/export.ndjson

The whole list. By default only confirmed, invited and joined people, so unconfirmed addresses don't end up in your newsletter tool. Add ?status=all for everyone, or ?status=pending for one status.

curl -o list.csv https://trylobby.app/v1/export.csv -H "Authorization: Bearer sk_…"

Webhooks and deliveries

GET/v1/webhooks

POST/v1/webhooks

{ "url": "https://orbit.app/hooks/lobby", "kind": "standard", "events": ["signup.confirmed"] }

kind is standard or slack. Leave out events to get all of them. The response includes the signing secret, shown only this once.

DELETE/v1/webhooks/{id}

POST/v1/webhooks/{id}/test

Sends a webhook.test event.

GET/v1/deliveries

POST/v1/deliveries/{id}/redeliver

Recent deliveries with their status, attempts and last response, and a way to send one again. See Webhooks.

Broadcasts

POST/v1/broadcasts

{ "subject": "Orbit is live", "body": "Thanks for waiting…", "audience": "confirmed" }

audience is confirmed, invited or all. Unsubscribed people are skipped. The body is plain text.

Public endpoints

These take the public key and need no authentication. They're what the widget uses.

POST/v1/w/{pk}/signup

Adds someone to the list. See From your own code.

GET/v1/w/{pk}/count

{"count": 1204}, or {"count": null} below the project's counter floor.
