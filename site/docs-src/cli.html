Install

Build it with Go 1.26 or later:

go install github.com/rohansx/lobby/cmd/lobby@latest

Or run it from the Docker image, where it's also linked as wl:

docker run --rm -e LOBBY_URL -e LOBBY_KEY ghcr.io/rohansx/lobby wl stats

Configure

Point it at an instance and a project with two environment variables:

export LOBBY_URL=https://trylobby.app
export LOBBY_KEY=sk_…        # the project's secret key

On Lobby Cloud this needs the Launch or Pro plan, like the rest of the API.

Commands

CommandWhat it does
lobby statsCounts by status, confirm rate, top sources.
lobby signups [--status S] [--q Q] [--limit N] [--json]List signups as a table, or JSON.
lobby invite --next N [--dry-run]Invite the next N people in line. --dry-run shows who without sending.
lobby invite --ids 12,13Invite specific people.
lobby joined IDMark someone as joined.
lobby remove [--hard] IDRemove someone; --hard deletes them and blocks the address.
lobby export [--format csv|ndjson] [--status all]Write the list to standard output.
lobby webhooksList the project's webhooks.
lobby serveRun the server (see Self-hosting).

Examples

# who would the next wave be?
lobby invite --next 100 --dry-run

# confirmed addresses at one company
lobby signups --status confirmed --q @acme.com --json | jq -r '.data[].email'

# nightly backup of the list
lobby export --format ndjson --status all > lobby-$(date +%F).ndjson
