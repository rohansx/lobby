Quick startA live waitlist on your site in about five minutes. Add it to your siteScript widget, plain HTML form, or a hosted page. REST APIRead signups, send invites and export your list. Self-hostingOne Docker container and one SQLite file.

How it fits together

Everything in Lobby belongs to a project, one per product you're launching. A project has:

  • a public key (pk_…) that goes in your page. It can only add people to the list, so it's safe to publish.
  • a secret key (sk_…) for the API and CLI. Keep it on your server.
  • a slug, which gives it a hosted page at /w/your-slug.
  • its own settings: double opt-in, how the line is ordered, referral caps, sender name, page copy and consent text.

A person moves through five states:

StatusMeaning
pendingSigned up, hasn't clicked the confirmation link yet. Not in line.
confirmedIn line, with a place and a referral link.
invitedYou let them in. They have an invite link and a code.
joinedThey used the invite, or you marked them as joined.
removedTaken off the list, by you or by unsubscribing.

For coding agents

Every Lobby instance serves a plain-text summary of its API at /llms.txt. Point Claude, Cursor or any other agent at it and it can add the widget, read signups and send invites for you.
