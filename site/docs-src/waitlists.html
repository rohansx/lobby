Double opt-in

With double opt-in on (the default), a new signup is pending until the person clicks the link in the confirmation email. Only then do they get a place in line. This keeps typos, fake addresses and other people's addresses off your list, and it's what keeps your launch email out of spam folders.

Turning it off in Settings puts people in line the moment they sign up. Do that only if you verify addresses some other way.

Signing up again with the same address doesn't create a duplicate. It re-sends the confirmation or status email, at most once every ten minutes.

Duplicate addresses

Addresses are compared in a normalized form, so Jane.Doe+launch@gmail.com and janedoe@gmail.com count as the same person. That also stops people from inventing addresses to refer themselves.

Place in line

Choose the ordering in Settings → Ordering:

  • Points (the default): each credited referral moves the referrer up a set number of places, 10 unless you change Places per referral.
  • First come, first served: the order people confirmed in, with no jumping ahead.

Only confirmed people have a place. Someone moving up never changes anyone else's base position; the line is recomputed when it's read.

Referrals

Every confirmed person gets a referral link: your Site URL (or the hosted page if you haven't set one) with ?ref=code added. The widget and form pick up ?ref= from the page they're on.

A referral is credited only when the friend confirms their email, not when they sign up. Two caps stop one person from gaming it:

SettingDefaultWhat it limits
Referrals credited per IP3Credited referrals coming from the same IP address.
Referrals credited per hour20Credited referrals for one referrer in an hour.

Referrals beyond a cap still join the list; they just don't move the referrer up.

The status page

The confirmation link opens the person's status page at /s/…. They click once to confirm (a button rather than the link itself, so email scanners that open links can't confirm on someone's behalf). The page then shows their place, how many people are behind them, how many friends they've referred, and their referral link with copy, X, LinkedIn and email share buttons. The link in later emails opens the same page, so they can check back any time without an account.

Turn off Show place in line if you'd rather not reveal numbers; the page then shows the referral link only.

The public counter

GET /v1/w/{pk}/count and the widget's data-counter show how many people are on the list. Below the Public counter starts at number (50 by default) they return nothing, so a brand-new list never says "3 people are waiting."

Removing people

Removing someone from the dashboard or with DELETE /v1/signups/{id} marks them removed and keeps the record. Add ?hard=1 to delete them entirely; Lobby keeps only a one-way hash of the address so the same address can't be signed up again by a bot.

Privacy

  • IP addresses are stored only as keyed hashes, and cleared after 30 days.
  • Public pages and the widget set no cookies.
  • The consent text is versioned; each signup stores the version they agreed to.
  • You can export everything as CSV or NDJSON at any time.
