Adding a webhook

In the project's Webhooks page, add the URL, choose the events, and copy the signing secret (whsec_…). It's shown once. You can also create webhooks through the API.

Choose Slack as the kind and paste a Slack incoming-webhook URL to get a readable message in a channel instead of JSON.

On Lobby Cloud, webhooks come with the Launch and Pro plans.

The webhook-id is the same across retries of one event, so use it to ignore duplicates.

Verifying the signature

Lobby signs every request following Standard Webhooks, so any of their libraries can check it:

import { Webhook } from "standardwebhooks"

const wh = new Webhook(process.env.LOBBY_WEBHOOK_SECRET.replace("whsec_", ""))

app.post("/hooks/lobby", express.raw({ type: "application/json" }), (req, res) => {
  const event = wh.verify(req.body, req.headers) // throws if the signature is wrong
  // handle event.type …
  res.sendStatus(204)
})

Or by hand: the signature is HMAC-SHA256 over {webhook-id}.{webhook-timestamp}.{raw body}, keyed with the base64-decoded part of the secret after whsec_, base64-encoded and prefixed with v1,.

func verify(secret, id, ts, sig string, body []byte) bool {
	key, _ := base64.StdEncoding.DecodeString(strings.TrimPrefix(secret, "whsec_"))
	mac := hmac.New(sha256.New, key)
	fmt.Fprintf(mac, "%s.%s.", id, ts)
	mac.Write(body)
	want := "v1," + base64.StdEncoding.EncodeToString(mac.Sum(nil))
	for _, s := range strings.Fields(sig) {
		if hmac.Equal([]byte(s), []byte(want)) {
			return true
		}
	}
	return false
}

Also reject requests whose webhook-timestamp is more than five minutes from your clock, so an old request can't be replayed.

Retries

Any 2xx answer counts as delivered. Anything else, or no answer within 15 seconds, is retried after 5 seconds, 5 minutes, 30 minutes, 2 hours, 5 hours, 10 hours and 10 hours: eight attempts over about a day. After that the delivery is marked failed.

Answer 410 Gone to turn the webhook off for good.

The Webhooks page lists recent deliveries with their response codes and errors, and Redeliver sends any of them again.
